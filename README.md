# GA-TaPhoi-Equipment-Selection

Mã nguồn Python thực thi mô hình tối ưu hóa đồng bộ thiết bị xúc - vận (ĐBTB) tại mỏ đồng Tả Phời sử dụng thuật toán di truyền (GA) để tối đa hóa NPV.

## Cấu trúc thư mục:
- `main.py`: File thực thi chính chạy thuật toán di truyền.
- `config.py`: Các thông số kinh tế - kỹ thuật đầu vào của mỏ Tả Phời.
- Thư mục `modules/`: Chứa các module chức năng tính toán chi phí, năng suất, và hàm phạt.

## Hướng dẫn chạy chương trình:
1. Cài đặt Python (phiên bản >= 3.10).
2. Tải mã nguồn về máy.
3. Chạy lệnh: `python main.py` để bắt đầu quá trình tối ưu hóa và xuất kết quả.
Sau đó bấm Commit changes để lưu lại.
